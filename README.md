# Garmin Now Playing

פני שעון מינימליסטיים ל-Garmin Venu 3 שמציגים שעה, תאריך ואת השיר שמתנגן ב-YouTube Music, יחד עם אפליקציית אנדרואיד נלווית ששולחת את השיר לשעון.

- `android/` – אפליקציית האנדרואיד (Kotlin)
- `garmin/` – פני השעון (Monkey C, Connect IQ)
- `.github/workflows/` – בנייה אוטומטית בענן של שני החלקים

## איך זה עובד

1. האפליקציה בטלפון מקבלת "גישה להתראות". ההרשאה הזו מאפשרת לה לקרוא את נגן המדיה של YouTube Music: שם השיר, האמן ומצב הניגון.
2. בכל שינוי (שיר חדש, השהיה, עצירה) היא שולחת הודעה קצרה לשעון דרך Garmin Connect, בעזרת Connect IQ Mobile SDK הרשמי. הודעה זהה לקודמת לא נשלחת שוב.
3. בשעון, שירות רקע של פני השעון מתעורר כשמגיעה הודעה (`Background.registerForPhoneAppMessageEvent`), שומר אותה ומעביר אותה לפני השעון.

הכול מבוסס אירועים: אין בדיקה מחזורית בטלפון או בשעון.

## מה מוצג בשעון

| מצב | תצוגה |
|---|---|
| מתנגן | שם השיר בלבן והאמן מתחתיו |
| מושהה | שם השיר מעומעם, עד 30 דקות |
| נעצר / YouTube Music נסגר | שעה ותאריך בלבד |
| הטלפון מנותק מהשעון | שעה ותאריך בלבד |
| "מתנגן" בלי שום עדכון במשך 3 שעות | שעה ותאריך בלבד |

במסך התמידי (Always-On) הצבעים מעומעמים והתצוגה זזה כמה פיקסלים כל דקה, לפי כללי ההגנה מצריבה של Garmin.

## התקנה

### אפליקציית האנדרואיד

1. הורד והתקן את `NowPlaying.apk` מ-[הגרסה האחרונה](https://github.com/dor-ovadia/garmin-now-playing/releases/tag/android-latest).
2. פתח את האפליקציה ולחץ **פתח הגדרות גישה להתראות**, והפעל את **Now Playing**.
   - אם המתג אפור: הגדרות הטלפון ← יישומים ← Now Playing ← שלוש הנקודות ← **אפשר הגדרות מוגבלות**, ואז נסה שוב.
3. הגדרות הטלפון ← יישומים ← Now Playing ← סוללה ← **ללא הגבלה**, כדי שהטלפון לא יסגור את האפליקציה.
4. ודא ש-Garmin Connect מותקן ושהשעון מחובר.

### פני השעון

פני השעון מותקנים כ"אפליקציית בטא" פרטית בחנות Connect IQ (רק בעל החשבון רואה אותה).

1. הורד את `NowPlaying.iq` מ-[הגרסה האחרונה](https://github.com/dor-ovadia/garmin-now-playing/releases/tag/garmin-latest).
2. ב-`apps-developer.garmin.com` העלה את הקובץ (בפעם הראשונה: אפליקציה חדשה עם הסימון **Beta**; בהמשך: **העלה גרסה חדשה**).
3. בטלפון פתח את `https://apps.garmin.com/apps/<מזהה-האפליקציה-בחנות>` (לא את הכתובת של אתר המפתחים), והתקן דרך אפליקציית Connect IQ.
4. לעדכון גרסה: הסר את פני השעון ב-Connect IQ והתקן מחדש.
5. בשעון: לחיצה ארוכה על המסך ← פני שעון ← Now Playing.

## בנייה

כל דחיפה למאגר בונה את החלק שהשתנה ב-GitHub Actions ומפרסם את הקבצים להורדה.

בניית פני השעון דורשת שלושה סודות במאגר (Settings ← Secrets and variables ← Actions):

| שם | תוכן |
|---|---|
| `GARMIN_USERNAME` | המייל של חשבון Garmin (להורדת ה-SDK) |
| `GARMIN_PASSWORD` | הסיסמה של חשבון Garmin |
| `CIQ_DEVELOPER_KEY` | מפתח החתימה של Connect IQ בפורמט DER, מקודד ב-base64 |

אם משנים את מזהה האפליקציה ב-`garmin/manifest.xml`, יש לעדכן גם את `WATCH_APP_ID` ב-`GarminLink.kt`.

## פתרון בעיות

פתח את אפליקציית Now Playing בטלפון. מסך האבחון מראה איפה השרשרת נקטעת:

| מה רואים | מה לעשות |
|---|---|
| גישה להתראות: לא מאושרת | לאשר בהגדרות (ראה התקנה, שלב 2) |
| שיר: — בזמן ששיר מתנגן | לוודא שהשיר מתנגן ב-YouTube Music ולא באפליקציה אחרת; לכבות ולהדליק את הגישה להתראות |
| חיבור Garmin: שגיאת אתחול | לפתוח את Garmin Connect ולוודא שהשעון מחובר; לפתוח מחדש את Now Playing |
| שליחה אחרונה: אין שעון מחובר כרגע | ה-Bluetooth מנותק; ההודעה תישלח כשהשעון יחזור |
| שליחה אחרונה: השליחה נכשלה | לוודא שפני השעון Now Playing מותקנים בשעון |
| נשלח בהצלחה אבל השעון לא מציג | לוודא ש-Now Playing הם פני השעון הפעילים; לעבור לפני שעון אחרים ולחזור |
| השיר נעלם מהשעון | זה מכוון אחרי 30 דקות השהיה, או כשהטלפון מתנתק |
| המסך התמידי כבה | בשעון: הגדרות ← תצוגה ← לוודא ש-Always On מופעל |

הכפתור **שלח הודעת בדיקה לשעון** שולח שיר לדוגמה, כדי לבדוק את הערוץ בלי YouTube Music.

## מגבלות ידועות

- שירות הרקע של פני השעון רץ רק כש-Now Playing הם פני השעון הפעילים.
- בזמן פעילות ספורט בשעון, או כשאפליקציה אחרת פתוחה בו, העדכון יופיע רק כשחוזרים לפני השעון.
- קודם כל נבדק ופועל על Venu 3 עם טלפון Samsung; שעונים אחרים לא נבדקו.
